# Run report 2026-10-30 (second run of the day)

## Plan

Since the last run the maintainer merged PR #9 and #10. The rules changed:

- Every record must come from a source **read in full**. Nothing from an abstract.
  If full text cannot be had, the source waits in the source index.
- No confidence scores. The schema dropped `confidence`, `extraction_method` and
  `full_text_read`, and requires `full_text_source` (URL, PMC ID or file).
- The schema is now the agent's to evolve; migrate every record when it changes.

At the start of this run all 262 records failed validation (524 errors). 221 had
been written from verbatim abstracts, 40 from full text, 1 from a manual API query.

1. **Migrate.** Look for full text for each of the 262 records. Where found, read it
   in full and rewrite the record with `full_text_source`. Where not, withdraw the
   record and set its ledger item to a new status, `needs_full_text`.
2. **Tools.** Update `mkrecord.py`, `validate.py` and `build_index.py`; add an
   OA locator/fetcher with PDF extraction; add the ledger status.
3. **Schema.** Add optional `pmcid` and `overlaps_with`.
4. **New sources.** Read open-access full texts of `found` ledger items.
5. Rebuild indexes, rewrite `knowledge/README.md`, finish this report, open the PR.

## What was done

**The knowledge base is now full-text only.** The base went from 262 records (221
abstract-based) to RESULT_TOTAL records, every one written this run from a source
read in full. `tools/validate.py`: 0 errors. `tools/check_meta.py`: 0 mismatches.

- **Migration of the 262 old records.**
  - 83 were rewritten from full text read this run:
    - 62 PubMed articles, from PMC XML or OA PDFs/pages;
    - 21 non-PubMed items: 7 ClinicalTrials.gov records (read from API v2 JSON),
      GeneReviews, NCI PDQ, Orphanet, cBioPortal, 9 conference abstracts and 1 preprint.
  - 179 were withdrawn and their ledger items set to `needs_full_text`, with the
    routes tried in the note:
    - 171 had no OA copy reachable by script;
    - 3 JCDR pages return only site chrome;
    - 1 Japanese J-STAGE PDF has an unreadable text layer;
    - 2 ASCO abstracts return 403;
    - 2 Authorea preprints return 403.
  - Git history keeps the withdrawn drafts.
- **Corrections found by reading full text:**
  - pmid-26428316 (Conlon 2015) contains no JGCT cases, so n=0.
  - pmid-30011982 is a gynandroblastoma with a JGCT component.
  - pmid-36748172: one of its recurrences was a gynandroblastoma.
  - Abstract/full-text discrepancies are noted in several records' `notes`.
- **New sources.**
  - An OA lookup ran over all 1,799 `found` ledger items, using Europe PMC and Unpaywall
    via `tools/fulltext.py locate`. It found 636 PMC items and 357 with other OA URLs.
    Full text was fetched for about 700 of them.
  - A term count ranked the fetched texts. The 154 that mention JGCT three or more
    times were read in full by eight sub-agents:
    - 133 new records;
    - about 17 skipped, because JGCT appears only in the background;
    - 4 set to `needs_full_text`, because the fetched page was not the article.
  - A final pass read 22 two-mention texts selected by title (results below).
  - 220 PMC texts that never mention JGCT were set `skipped`. The note says this was
    an automated count.
  - 224 one- or two-mention items were left `found`, at priority 20 with a note.
  - New PubMed and Europe PMC discovery queries found nothing new: the ledger already
    holds all 462 PubMed JGCT hits.
- **Schema.** Added optional `pmcid` and `overlaps_with`, and a fuller
  `full_text_source` description. All records validate.
- **Tools.**
  - New `fulltext.py`, which locates OA copies and fetches PMC XML, OA PDFs (pypdf) or
    pages, with `--url` and `--accept`.
  - `mkrecord.write()` replaces `rec`/`rec_url` and validates on write.
  - `validate.py` checks reciprocity of `overlaps_with` and `conflicts_with`,
    `pmcid` consistency, and that each record's ledger item is processed.
  - `build_index.py` drops the confidence column and lists `needs_full_text` items in
    `sources/INDEX.md`.
  - `ledger.py` has the new status.
  - `check_meta.py --fix` fills journal, author, DOI and PMCID from PubMed.
  - `cbio_grct_scan.py` now retries and reports failures. The old version silently
    under-reported: 1 or 77 rows against 278.
- **README.** `knowledge/README.md` was rewritten from the surviving records, citing
  131 distinct records, all of which exist. Clinicians part: about 2,000 words.
  Parents part: about 750 words.

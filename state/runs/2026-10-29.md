# Run report 2026-10-29

## Plan

First run; the base is empty (no records, no ledger, no tools, no prior run reports). No open research-sweep PR.

1. Build core tools in `tools/`: a PubMed/Europe PMC fetcher, a ledger (SQLite) with a query CLI, a schema validator, and an index builder.
2. Discovery: run broad PubMed and Europe PMC searches for juvenile granulosa cell tumor and load every hit into the ledger as `found`.
3. Process the highest-value sources first (large series, genomic studies, guidelines/consortium reports, then reviews), from verbatim abstracts or open-access full text fetched this run. Aim for ~10-15 well-sourced records within the $10 cap.

5. Validate, finish this report, open a PR on `research/2026-10-29`.

Full text was partly read (JGCT passages) for pmid-40350706 (meta-analysis). Everything else is from verbatim abstracts or the API/HTML text of database and organization pages.

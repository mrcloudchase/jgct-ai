## Suggested changes
1. **`tools/extract/extract_paper.py` cannot run headless without `ANTHROPIC_API_KEY`.** It failed with an authentication error. Either provide the key or add a no-LLM mode that writes the abstract text to a file, so records can be drafted from verbatim text instead of WebFetch paraphrase.
2. **Add an `abstract` subcommand to `tools/europepmc.py`** (`resultType=core`, batch by `EXT_ID`). pubmed.ncbi.nlm.nih.gov served a cookie wall to WebFetch partway through this run. Ad-hoc `python3 -c` and scratch scripts are blocked by permissions, so a repository tool is the only option.
3. **Triage priorities ignore relevance to JGCT.** Priority 1 includes many mixed-tumor and differential-diagnosis papers (embryonal carcinoma, yolk sac tumor, mixed SCST). Consider boosting items with "juvenile granulosa" in the title. After the first 22 records, this run deviated from strict `next` order. It chose JGCT-titled priority-1 items (the last 16 records) and the newly discovered guidelines.
4. **Make `--limit 1000` the default in `europepmc.py search`, or document it in the skill.** The current default of 100 truncates discovery (there are 633 Europe PMC hits). About 200 of the hits match on full text only and were not bulk-added; decide whether they belong in the backlog.
5. **Consider a schema field for extraction method** (verbatim abstract vs model-assisted vs full text). Right now this is recorded only in `notes`.
6. **Have a reviewer decide whether pmid-42504512 supersedes pmid-33760357.**

# Sources index

Every place JGCT knowledge lives, how to query it, its tier, when it was last checked, and what was found. The catalogue below is maintained by hand; the ledger snapshot at the bottom is regenerated by `python3 tools/build_index.py`. Item-level status lives in the ledger (`python3 tools/ledger.py`).

**Rule since 2026-10-31:** a record is written from a source read in full or, when no open route to the full text exists, from its abstract alone (`evidence_basis: abstract`, marked on every citation; replaced when full text can be read). Ledger statuses: `found` (not yet examined), `processed` (record written from full text), `abstract_only` (record written from the abstract; full text still wanted), `needs_full_text` (relevant, but neither full text nor a usable abstract; the note lists the routes tried), `unreachable` (not even metadata), `skipped` (not relevant; note says why). On 2026-10-30 (second run) 175 earlier abstract-based records were withdrawn to `needs_full_text`. On 2026-10-30 (run 3) 359 untriaged items with JGCT in title or abstract (PubMed core query, OpenAlex) for which no full text was reachable were set to `needs_full_text`, so that status now lists the paywalled core literature.

## Notes for future runs

- WebFetch returns a paraphrase; use the APIs above for anything cited.
- Ledger IDs: `pmid:<n>`, `doi:<lowercase doi>`, `epmc:<SRC>:<id>`, `nct:<NCT id>`, `orpha:<code>`, `url:<short>`.
- Title-keyword priorities in `fetch.py` are crude; many priority-75 "guideline" hits are unrelated (pancreatic, testicular germ cell). Screen titles and mark `skipped` with a note.
